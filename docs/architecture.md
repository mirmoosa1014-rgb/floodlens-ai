# Architecture

`simulation.py` owns terrain, dry/wet storage, edge fluxes, rainfall, drainage, outflow and budget residuals. `policy.py` chooses fixed gauges without water truth, constructs causal features, plans feasible inspection arrivals, acquires noisy arrival-time point observations and applies causal corrections. `dataset.py` keeps scenario families/episodes intact. `model.py` trains an eight-feature standardized ridge regressor stored as inspectable JSON. `experiment.py` calibrates on validation residuals, evaluates heldout families, and writes CSV/JSON/figures. `api.py` validates bounded requests and serves React build output. React canvas projects actual terrain/water elevation in 3D; SVG aligns forecasts with future target time.

A cell stores depth h in metres over 144 m². Each dt ≤20 s step adds uniform rainfall except impermeable cells, removes bounded drainage (1e−6 m/s), transfers water down free-surface head gradients along orthogonal edges with k=0.003 s⁻¹, and drains the south boundary at 0.0008 s⁻¹. Each donor scales total outgoing flux to available storage, preserving positivity. Edge transfers enter one cell and leave another. Budget residual is Δstorage − rain + drain + boundary_outflow. Impermeable faces transfer zero water. This is a linear storage network; it does not solve momentum or Manning flow.

At maximum dt, four edge conductances sum to 0.24 before boundary loss. Donor limiting also preserves nonnegative depth. Same-network time refinement is meaningful; grid-refinement equivalence is not, because conductance is not derived as diffusivity/dx². The terrain creates a low channel and mild perturbations; six synthetic points stand in for road crossings.

Features never read future depth/rain. The API sends full truth explicitly for visualization only. Gauge noise is seeded with seed/time/row/column so equal site/time evidence is paired across policies. Route planning consumes a then-issued forecast only. A point observation becomes available at ceil((start+arrival)/dt); forecasts before that step stay unchanged. Correction uses the arrived depth plus the causal forecast's recent predicted change, expires after 180 s, and does not pretend to be a complete spatial assimilation filter. Both distance and service/travel time include return reserve.

Technical references consulted during development: [USACE diffusion-wave solver](https://www.hec.usace.army.mil/confluence/hecras/latest/technical-reference/numerical-methods/diffusion-wave-solver) for the distinction between conservative numerical storage and full dynamics (this code is not HEC-RAS); [NumPy solve](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html) for the ridge normal-equation solve. No third-party hydraulic solver or field dataset is incorporated.
