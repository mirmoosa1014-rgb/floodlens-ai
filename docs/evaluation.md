False-alert rate = FP/(TN+FP), recall = TP/(TP+FN), with denominator bounded at one if empty. The first-alarm lead metric accounts for +3-step forecast target alignment, then compares first pre-onset alarm with synthetic onset. A zero can mean no timely alarm or no event; it is not an operational warning test. Inspection comparison uses fixed 420 m, 120 s budgets with 6 m/s travel, 5 s dwell and return reserve. Unvisited crossings count as missed inspections, not automatically missed flood events. Both routes receive the same site/time noise when they observe a common location/time. The priority route does not use future depths.
