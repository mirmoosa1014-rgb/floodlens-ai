# 90-second demo

0–15 s: state that all terrain/water are synthetic and never road-safety guidance. Distinguish surface elevation from depth.
15–35 s: animate and rotate. Point out three green gauges, six yellow crossing locations and the dashed inspection route.
35–55 s: choose a crossing. Blue is withheld simulator truth; green is a causal forecast at +60 s. Scrub time before/after arrival: point readings appear only after travel/dwell and temporarily update that crossing.
55–75 s: change gauge layout with fixed storm/terrain; rerun. Compare forecast behavior, not merely water color. Change inspection priority to nearest-site baseline.
75–90 s: show measured CSV and quick run where ML loses. Highlight low interval coverage and the small route-policy difference. Explain that real use would require calibrated physics, real terrain and independent field validation.
